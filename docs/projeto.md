# Projeto e entregas

## Repositório

Padrão previsto:

```text
soufer-tools/
├── api/
├── web/
└── docs/
```

Branches:

```text
main
  ↑
develop
  ↑
feat/*
```

## Commits

Utilizar Conventional Commits.

Exemplos:

```text
feat: adiciona cadastro de ferramentas
fix: corrige validação de devolução
docs: atualiza documentação da API
refactor: reorganiza serviço de empréstimos
test: adiciona teste de dias úteis
```

## Pull Requests

- `main` protegida.
- PR com pelo menos um aprovador.
- Commits individuais e visíveis de todos os integrantes.

## Roteiro de demonstração

1. Cadastrar uma ferramenta.
2. Gerar o patrimônio.
3. Imprimir a etiqueta.
4. Ler o código com leitor físico.
5. Ler o crachá do colaborador.
6. Demonstrar cadastro rápido de colaborador.
7. Selecionar atividade e confirmar retirada.
8. Tentar retirar novamente a mesma ferramenta e demonstrar o `409`.
9. Devolver com avaria.
10. Demonstrar abertura automática da ocorrência.
11. Demonstrar a área de indisponíveis.
12. Mostrar calendário e notificações.
